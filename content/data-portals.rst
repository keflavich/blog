Homemade Data Portals
#####################
:date: 2026-09-03 09:32 
:author: Adam Ginsburg (Adam.G.Ginsburg@gmail.com)
:tags: tags


I've been making custom 'data portals' to explore spectral + photometric and photometric-only datasets from JWST especially.  Claude has accelerated this from few-week, dedicated projects to one-liners.

One example is this one, which uses all of the MSA spectra from the MAST archive and plots them as color-color diagrams.
https://data.rc.ufl.edu/pub/adamginsburg/jwst/spectra/portal/index.html

I'll post more of these asa I make them public.  The data.rc.ufl.edu links may have to be taken down or replaced if more than a handful of people use them.

I host more high-bandwidth things on starformation.astro.ufl.edu, such as the Roman footprint viewer:
https://starformation.astro.ufl.edu/roman/roman_footprint_rotatable.html
which uses aladin-lite but has a bunch of pointings of Roman overlaid.
